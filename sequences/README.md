# Sequences

## Overview

This folder contains the nucleotide and protein sequences used in the computational analysis of the **blaTEM-1 β-lactamase gene** in *Escherichia coli*.

---

## Contents

This folder will contain:

- Wild-type nucleotide FASTA sequences
- Mutant nucleotide FASTA sequences
- Wild-type protein FASTA sequences
- Mutant protein FASTA sequences

---

## Purpose

The sequence files are used for:

- Multiple sequence alignment
- Mutation identification
- Translation into protein sequences
- Comparative sequence analysis

---

## Source Databases

- NCBI GenBank
- European Nucleotide Archive (ENA)

---

## File Formats

- .fasta
- .fa
- .txt

---

## Notes

The sequences included in this repository were obtained from publicly available databases and were used for the bioinformatics analyses described in this project.
