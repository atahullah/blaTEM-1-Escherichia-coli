# Data

## Overview

This directory contains the datasets used throughout the computational analysis of the **blaTEM-1 β-lactamase gene** in *Escherichia coli*. All datasets included in this repository are obtained from publicly available biological databases and were used for sequence retrieval, mutation identification, and structural analysis.

---

## Contents

This folder will contain:

- Wild-type nucleotide sequences
- Mutant nucleotide sequences
- Protein sequences
- Sequence metadata
- Reference sequence information

---

## Data Sources

The datasets used in this project were obtained from the following public databases:

- National Center for Biotechnology Information (NCBI)
- European Nucleotide Archive (ENA)
- RCSB Protein Data Bank (PDB)

---

## Sequence Information

The sequence datasets are used for:

- Identification of nucleotide mutations
- Translation into protein sequences
- Sequence comparison
- Mutation confirmation
- Structural bioinformatics analysis

---

## Notes

Only publicly available biological data are included in this repository.

The university thesis manuscript is **not** included in this repository.

All analyses documented here are part of the computational workflow used in this research project.
