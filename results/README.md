# Results

## Overview

This folder contains the final results obtained from the computational analysis of the **blaTEM-1 β-lactamase gene** in *Escherichia coli*.

---

## Contents

The results include:

- Mutation identification
- Sequence comparison
- Structural analysis
- Protein stability analysis
- Interaction analysis
- Summary tables

---

## Mutations Investigated

- I84V
- V184A

## Notes

The results presented in this folder summarize the complete bioinformatics workflow performed during this research project.

The findings are based on sequence analysis, structural visualization using PyMOL, and protein stability prediction using DynaMut2.
