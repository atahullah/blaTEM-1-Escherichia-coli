# DynaMut2

## Overview

This folder contains the protein stability analysis performed using **DynaMut2** for the V184A and I84V mutations in the **blaTEM-1 β-lactamase** protein of *Escherichia coli*.

---

## Objectives

The DynaMut2 analysis was performed to:

- Predict the effect of mutations on protein stability.
- Compare wild-type and mutant protein structures.
- Analyze intermolecular interactions.
- Evaluate structural changes caused by amino acid substitutions.

---

## Mutations Analyzed

- I84V
- V184A

---

## Contents

This folder may contain:

- DynaMut2 prediction reports
- ΔΔG stability results
- Interaction analysis
- Mutation screenshots
- Summary tables

---

## Software

- DynaMut2

---

## Notes

The stability analysis was performed using the TEM-1 β-lactamase crystal structure (PDB ID: 1BTL). The predicted effects of the I84V and V184A mutations were compared with the wild-type protein to evaluate changes in structural stability.
