# Figures

## Overview

This folder contains all figures generated during the computational analysis of the **blaTEM-1 β-lactamase** protein in *Escherichia coli*.

---

## Objectives

The figures are included to visually represent the results obtained during the study.

---

## Contents

This folder may contain:

- Sequence alignment images
- Mutation comparison figures
- PyMOL structure images
- Residue numbering images
- DynaMut2 interaction images
- Protein stability figures
- Workflow diagrams

---

## Image Formats

- PNG (.png)
- JPG (.jpg)
- TIFF (.tif)

---

## Notes

All figures included in this repository are generated as part of this research project and are intended to support the interpretation of the computational analyses.

Figures should be accompanied by clear captions and descriptions to ensure reproducibility and scientific clarity.
