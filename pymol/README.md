# PyMOL

## Overview

This folder contains molecular visualization files and images generated using **PyMOL** during the structural analysis of the **blaTEM-1 β-lactamase** protein from *Escherichia coli*.

---

## Objectives

The PyMOL analysis was performed to:

- Visualize the three-dimensional structure of TEM-1 β-lactamase.
- Verify amino acid residue numbering.
- Locate mutation positions.
- Compare wild-type and mutant protein structures.

---

## Protein Information

- Protein: TEM-1 β-lactamase
- Organism: *Escherichia coli*
- PDB ID: **1BTL**

---

## Contents

This folder may contain:

- PyMOL session files (.pse)
- Structure images (.png)
- Mutation visualization images
- Residue numbering screenshots

---

## Software

- PyMOL Molecular Graphics System

---

## Notes

PyMOL was used to verify the structural positions of the V184A and I84V mutations before protein stability analysis with DynaMut2.
