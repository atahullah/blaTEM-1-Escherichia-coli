# Project Summary

## Project Title

In Silico Structural and Functional Analysis of V184A and I84V Mutations in the blaTEM-1 Gene of Escherichia coli

---

## Objective

This project investigated the structural and functional effects of the I84V and V184A mutations in the TEM-1 β-lactamase protein using computational bioinformatics approaches.

---

## Bioinformatics Workflow

1. Sequence retrieval from NCBI and ENA
2. Sequence alignment using BioEdit
3. Protein translation
4. Protein structure retrieval (PDB ID: 1BTL)
5. Structural visualization using PyMOL
6. Protein stability analysis using DynaMut2
7. Structural comparison and interaction analysis

---

## Software Used

- BioEdit
- PyMOL
- DynaMut2
- RCSB Protein Data Bank
- NCBI
- ENA

---

## Repository Contents

This repository includes:

- Project documentation
- DynaMut2 analysis
- PyMOL session files
- TEM-1 crystal structure (1BTL)
- Structural interaction analysis
- Research workflow
- Figures and supporting documentation

Some intermediate alignment files generated during the study are not included because they are no longer available. However, the computational workflow, structural analyses, and final research results are fully documented.

---

## Conclusion

The I84V and V184A mutations altered residue interaction networks within the TEM-1 β-lactamase protein, indicating structural changes that may influence protein stability and function. This repository provides the complete computational workflow and supporting analyses performed during this undergraduate research project.
