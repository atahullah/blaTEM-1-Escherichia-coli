# Workflow

## Overview

This folder documents the complete computational workflow used to analyze the **blaTEM-1 β-lactamase gene** in *Escherichia coli*.

---

## Research Workflow

### Step 1 – Sequence Retrieval

- Download wild-type and mutant nucleotide sequences from NCBI and ENA.

### Step 2 – Sequence Alignment

- Perform multiple sequence alignment using BioEdit.
- Identify nucleotide mutations.

### Step 3 – Protein Translation

- Translate nucleotide sequences into protein sequences.
- Identify amino acid substitutions.

### Step 4 – Protein Structure Retrieval

- Download the TEM-1 β-lactamase crystal structure (PDB ID: 1BTL) from the RCSB Protein Data Bank.

### Step 5 – Structural Visualization

- Visualize the protein structure using PyMOL.
- Verify amino acid residue numbering.
- Locate mutation sites.

### Step 6 – Protein Stability Analysis

- Analyze the mutations using DynaMut2.
- Compare the stability of wild-type and mutant proteins.

### Step 7 – Result Interpretation

- Compare structural changes.
- Summarize mutation effects.
- Prepare tables and figures.

---

## Software Used

- BioEdit
- PyMOL
- DynaMut2
