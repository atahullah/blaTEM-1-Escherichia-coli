# Structures

## Overview

This folder contains the three-dimensional protein structure files used in the structural analysis of the **blaTEM-1 β-lactamase** from *Escherichia coli*.

---

## Objectives

The structural data were used to:

- Visualize the wild-type TEM-1 protein.
- Verify amino acid residue numbering.
- Locate mutation sites.
- Prepare structures for stability analysis.

---

## Protein Structure

- Protein: TEM-1 β-lactamase
- Organism: *Escherichia coli*
- PDB ID: **1BTL**
- Source: RCSB Protein Data Bank

## Notes

The TEM-1 crystal structure (PDB ID: 1BTL) was used as the reference structure for mapping and analyzing the V184A and I84V mutations.
