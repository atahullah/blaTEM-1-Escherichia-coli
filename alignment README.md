# Alignment

## Overview

This folder contains sequence alignment files generated during the comparative analysis of the **blaTEM-1 β-lactamase gene** in *Escherichia coli*.

---

## Objectives

The alignments were performed to:

- Compare wild-type and mutant nucleotide sequences.
- Identify nucleotide substitutions.
- Translate nucleotide sequences into protein sequences.
- Compare amino acid sequences.
- Confirm mutation positions.

---

## Software Used

- BioEdit Sequence Alignment Editor

---

## Alignment Files

This directory may contain:

- Nucleotide sequence alignments
- Protein sequence alignments
- Mutation comparison tables

---

## File Formats

- `.aln`
- `.txt`
- `.fasta`

---

## Notes

Multiple sequence alignment was performed using BioEdit to identify nucleotide and amino acid mutations before structural analysis.

The alignment results were used for downstream protein structure and stability analyses.
