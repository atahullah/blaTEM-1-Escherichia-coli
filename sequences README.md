# Sequences

## Overview

This folder contains the nucleotide and protein sequences used in the computational analysis of the **blaTEM-1 β-lactamase gene** in *Escherichia coli*.

---

## Contents

This directory includes:

- Wild-type nucleotide FASTA sequences
- Mutant nucleotide FASTA sequences
- Wild-type protein FASTA sequences
- Mutant protein FASTA sequences

---

## Purpose

The sequence files are used for:

- Multiple sequence alignment
- Mutation identification
- Translation of nucleotide sequences into protein sequences
- Comparative sequence analysis
- Structural bioinformatics analysis

---

## File Formats

The following file formats may be included:

- `.fasta`
- `.fa`
- `.txt`

---

## Source Databases

The sequences used in this project were obtained from:

- National Center for Biotechnology Information (NCBI)
- European Nucleotide Archive (ENA)

---

## Research Workflow

The sequence data were used in the following workflow:

1. Retrieve wild-type and mutant sequences from NCBI and ENA.
2. Perform multiple sequence alignment using BioEdit.
3. Identify nucleotide mutations.
4. Translate nucleotide sequences into protein sequences.
5. Compare wild-type and mutant proteins.
6. Prepare sequences for structural analysis using the TEM-1 crystal structure (PDB ID: 1BTL).

---
